# Contributing to Arlecchino

Thank you for wanting to help.

## How to propose a change

1. Bugs and ideas: open an issue and describe what you saw and what you expected.
2. Code, documentation or translations: fork the repository, create a branch
   from `main`, keep the change focused, and open a pull request against
   `main`. Say what the change does and why.
3. If your change touches code, run the existing tests (`cargo test`) before you open
   the pull request.

## Contributor License Agreement

Pull requests are merged only if you agree to the
[Contributor License Agreement](CLA.md). To agree, post a comment with the
exact text `I agree to the CLA` on your pull request; the CLA bot records your
signature and the required "CLAAssistant" check turns green. You only need to
do this once per repository; it covers your future contributions too.

In short: you keep the copyright and authorship of your work, and you give the
maintainer a broad, permanent license to use it, including the right to release
the project under a different license. Please read [CLA.md](CLA.md) for the
exact terms.
